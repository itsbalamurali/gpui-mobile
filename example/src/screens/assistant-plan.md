### A focused first release

Make one conversation feel complete before adding more ways to start one.

| Essential | Why it matters |
| :--- | :--- |
| **Send & stop** | The user stays in control |
| **Rich replies** | Ideas need more than plain text |
| **Copy & retry** | Useful answers are easy to keep |
| **History** | Work continues across sessions |

#### Design the whole reply

1. **Before the answer**
   - Keep the user’s question visible.
   - Show a quiet *Thinking…* state.
2. **While it arrives**
   - Let paragraphs settle into place.
   - Keep Stop within reach.
3. **After it finishes**
   - Place Copy next to the answer.
   - Invite a useful follow-up.

> A good first release finishes a small job well. It does not need to expose every feature.

Keep voice, attachments and model selection for a later iteration.
